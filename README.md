# BlackVision Aenya OS v8.0
> **Autonomous AI-Chrome Fusion Framework**

Aenya OS is a next-generation automation architecture that merges LLM reasoning with bare-metal hardware execution. Unlike standard bots, Aenya operates directly within persistent Chrome profiles, allowing for seamless interaction with authenticated web environments.

## 🚀 Core Architecture (The 4 Pillars)
*   **Chrome Fusion:** Total access to authenticated sessions (Gmail, Facebook, Notion) using real persistent profiles. No API limitations.
*   **Autonomous Agent Hive:** Dynamic generation and execution of "Soldier" scripts via Playwright/Selenium on the fly.
*   **Tactical Vision & Memory:** Real-time logging, automated screenshots, and a persistent SQLite knowledge base.
*   **Hybrid Intelligence:** Integrated multi-key rotation (Groq/Llama 3.1) and reative command processing via Gmail/Notion.

## 🛠️ Modes of Operation
1.  **Full Fusion (Bare Metal):** Real-world execution with hardware-bound credentials and deep system integration.
2.  **Docker Demo Mode (Sandbox):** Simplified environment for architectural review, showing agent generation and log flow without local dependencies.

## 🧬 Tech Stack
*   **Language:** Python 3.11+
*   **Automation:** Playwright / Selenium
*   **Brain:** Groq / Llama 3.1 70B
*   **Storage:** SQLite / JSON Long-term memory
*   **Integrations:** Gmail API / Notion SDK
